# Instructions simples — Options Strategy Studio V1.4.0

1. Ouvrez le portail, puis cliquez sur **Studio d’options**.
2. Choisissez un modèle ou ajoutez une action, un call ou un put.
3. Remplacez toutes les valeurs d’exemple par vos propres hypothèses.
4. Consultez le sommaire, le graphique et le tableau.
5. Utilisez les curseurs pour changer la date projetée ou la volatilité.
6. Cliquez sur **Définir comme originale**, modifiez la stratégie, puis comparez les deux scénarios.
7. Cliquez sur **Enregistrer localement** pour la garder dans ce navigateur.
8. Utilisez **Exporter JSON** pour une copie privée.

N’ajoutez jamais un fichier JSON privé au dépôt GitHub. Le Studio est un outil pédagogique; il ne garantit aucun rendement et ne reproduit pas exactement la marge du courtier.
